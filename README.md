# MaxStyle

Мобильное веб-приложение салона красоты: каталог услуг, мастера, онлайн-запись в 4 шага, список своих записей с переносом и отменой.

Минималистичный монохромный стиль с красным акцентом, простые линейные иконки, светлая и тёмная темы.

Открыть: https://michirusudsumi.github.io/maxstyle/

Записи хранятся в браузере устройства (localStorage).
